1. Идентификација на проблемот 
•	Анализираме два клучни предизвици кај адолесцентите (11-15 години): училишен стрес и квалитет на сон. Истражувањата од HBSC покажуваат дека овие фактори се директно поврзани и влијаат на целокупната добросостојба. 
2. Дигитално решение 
•	Решението претставува интерактивен веб-дашборд изработен во Python со помош на Streamlit библиотеката. 
•	Апликацијата користи динамични филтри кои овозможуваат споредба на нивото на стрес и часовите на сон според возраст и пол, што ја прави алатката соодветна за едукативни цели. 
3. Техничка реализација 
•	Технологии: Python, Streamlit, Plotly (за визуелизација), Pandas (за обработка на податоци). 
•	Функционалност: Апликацијата генерира статистички модели во реално време, прикажувајќи корелација преку scatter plots и box plots. 
4. Очекуван импакт 
•	Ова решение служи како дигитална алатка за подигнување на свеста. Преку "AI Assistant" компонентата, корисниците добиваат персонализирани совети, што директно придонесува кон промовирање на здрави животни навики и психолошка добросостојба.
